  - **`src/voice/dictation.ts`** — `createDictation(doc, transcriber, getTarget)`. **Commit-on-final:** interim is exposed via `interimText`/`observeInterim` but NEVER written to Yjs; only finals insert at the caret, advance it, and fire `observeCommit`. Word/punctuation spacing join (`needsSpace`); interim clears on leave-`listening`; whitespace-only or no-target finals are no-ops.
  - **`src/doc/model.ts`** — added `insertBlockText(doc,id,offset,text,at?)` (insert-at-offset via `t.insert` inside `doc.transact` — preserves CRDT granularity, NOT the delete-all+reinsert of `setBlockText`) and `blockTextString` (reader for the join rule).

## 2. Decisions made and why
- **Web Speech API is the first runtime engine, behind the interface** (user-locked). Whisper-WASM can replace it in a later PR without touching the dictation core — the whole point of putting the engine behind `Transcriber`.
- **Commit-on-final** (user-locked): interim text is a preview only, never written to the CRDT — keeps undo history and peer/persistence broadcast clean; only finalized phrases mutate the block model.
- **The milestone is the composition, not the ASR.** P5.1's headline test proves dictation × relative-anchoring: dictating into a block *above* an anchored camera grows that block's estimated height, and the camera `{blockId, offset}` still resolves to the same content while `scrollTop` grows by exactly the above-growth — same shape as P4.5 composed the peer path with anchoring. In-memory (`Y.Doc` + fake + `computeLayout`/`deriveAnchor`/`HeightModel`), no server — correct scoping for an engine-independent core (adjudicator-confirmed intentional, not a shortcut vs the P4.5 e2e capstone).
- **Terminology: "interface", not "seam"** (user preference this session). New prose uses "interface"; legacy docs still say "seam" but that's not license to keep using it.
