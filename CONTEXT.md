## 2. Decisions and why
- **Enforce at COMMIT, at the authority.** The single-threaded room authority evaluate the guard against the AUTHORITATIVE doc, closing the check-then-act race. Op-grain refuse. PROVEN live (P6.6 milestone), not just unit-latent.
- **Belt + suspenders.** Agent picks cold (`coldBlocks`) = BELT; authority re-checks at commit (`guardedBlocks`) = SUSPENDERS. The milestone tests BOTH separately.
- **Provenance lives in the CRDT, coarse, per-block.** A Yjs transaction `origin` is local — it does NOT ride the wire — so a `lastAuthor` field on the block map is the only attribution every peer sees. Coarse (per-block, not per-run) is the honest first cut; the marker render is layout-neutral so it never violates P6.1. The guard treats an author stamp as a real write (signature includes `lastAuthor`) — a marker change under a live reader is still an uncoordinated write.
- **Provenance follows content, not keystrokes.** Split tail inherits the source author; merge survivor keeps its own; only a genuine text edit re-authors. Stamping 'human' on an unchanged block at Enter/Backspace would be a lie.
- **Fail closed everywhere.** null awareness / unplaceable camera / awareness outage → guard whole doc; dropped reader keeps band for `graceMs`.
